So, the null model is frozen and the repo is cleared up:

The readme file in the root directory gives you a concise overview of the current state. In the dev/ directory the development history is archived.

In a nutshell:
A zero-intelligence agent based model with longs and shorts trading through an order book based on simple rules of interaction. We get bubbles, crashes, trends, volatility clustering, fat tails, and some scaling laws similar to real FX data. There is no market maker, so the bid–ask spread is emergent (for a 10k run ~98% of ticks have both sides quoted, with a median spread of ~0.05%). The parameter space is constrained, as there are only four dials: when to open, when to close (take profit, stop loss, timer), wealth distribution, and trade size. Most of the development effort went into making the emergent behavior symmetrical. This was achieved by hunting every hidden mechanical bias (random ordering, symmetrical percentages, sizing symmetric at every price, own-currency settlement, no self-trading, ...).
